# HR Analytics Dashboard – Excel Data Cleaning & Analysis

An HR data analysis project developed using Microsoft Excel, covering data cleaning, exploratory analysis, KPI calculation, and interactive dashboard development.

## Project Workflow
- **Data Cleaning:** Prepared and cleaned raw HR data to improve data quality and consistency.
- **Data Analysis:** Analyzed employee attendance, punctuality, absenteeism, and workforce performance.
- **KPI Development:** Calculated key HR metrics to monitor employee attendance and performance.
- **Dashboard Development:** Created interactive Excel dashboards to visualize HR trends and insights.
- **Reporting:** Presented actionable insights to support data-driven HR decisions.

## Key Insights
- Employee punctuality rate and monthly trends.
- Absenteeism rates by job title.
- Employee attendance and performance indicators.
- Identification of employees requiring further review.

## Tools & Skills
- Microsoft Excel
- Data Cleaning & Data Preparation
- Exploratory Data Analysis (EDA)
- KPI Analysis
- Data Visualization & Dashboard Design
- HR Analytics & Reporting

## Objective
To transform raw HR data into meaningful insights through data cleaning, analysis, and visualization, helping HR teams monitor workforce attendance and make informed decisions.
